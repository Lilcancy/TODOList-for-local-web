# 今日待办 · TODO List

一个本地运行的待办事项网页：创建、完成、删除任务，实时显示当日日期与时间。原生 HTML/CSS/JS 编写，零依赖、零构建。

## 功能

- 创建任务（新任务置于顶部）
- 优先级标记：高 / 中 / 低，列表按优先级排序（点击任务上的标记可切换）
- 标记完成 / 取消完成
- 删除任务
- 行内编辑：双击任务文字，回车确认、Esc 取消
- 筛选：全部 / 未完成 / 已完成
- 剩余计数（"还有 N 项未完成"）
- 一键「清除已完成」
- 实时时钟：`2026年10月31日 星期六 14:30:25`
- 浅色 / 深色主题切换（默认跟随系统）

## 快速开始

需要本机装有 Python 3。

### 方式一：双击脚本（推荐）

| 操作 | 文件 |
| --- | --- |
| 启动 | 双击 `start-server.bat` —— 后台起服务并自动打开浏览器 |
| 停止 | 双击 `stop-server.bat` |

脚本用 `pythonw` 在**后台**运行服务，不占用终端窗口。

### 方式二：命令行

```bash
cd TODO_list
python -m http.server
```

然后浏览器打开 <http://localhost:8000>。

> 注意：本项目使用浏览器原生 ES 模块，必须通过 `http://` 访问，不能用 `file://` 直接双击 `index.html`。

## 技术栈

- 原生 HTML / CSS / JavaScript（ES 模块）
- 无框架、无构建工具、无第三方依赖
- 数据存储：`localStorage`

## 项目结构

```
TODO_list/
├── index.html          页面结构
├── styles.css          样式（浅色 + 深色主题）
├── start-server.bat    后台启动脚本
├── stop-server.bat     停止脚本
└── js/
    ├── app.js          入口：接线、绑定事件、协调各模块
    ├── store.js        数据层：localStorage 读写 + 增删改查
    ├── renderer.js     视图层：渲染列表、筛选、计数
    └── clock.js        日期时间：实时刷新
```

## 数据存储说明

任务数据保存在浏览器的 `localStorage` 中，按 `http://localhost:8000` 这个"源"隔离：

- 关闭服务、重启浏览器、重启电脑，数据都还在（与静态服务器无关）。
- 请固定使用同一端口访问（如始终 `http://localhost:8000`），换端口或改用 `file://` 会读不到已有数据。
- 数据按浏览器 / 用户档案隔离，不跨设备；清除浏览器数据或无痕模式会清空。
