# TODO List — 需求与设计文档

> 记录日期：2026-10-31

## 1. 项目概述

一个本地运行的 TODO List 网页，支持任务创建、标记完成、删除，并在页面显示当日日期与实时时间。项目遵循模块化开发原则，便于后续维护、优化与新增功能模块。

## 2. 技术栈

| 项 | 选择 |
| --- | --- |
| 语言 | 原生 HTML / CSS / JavaScript（浏览器原生 ES 模块） |
| 框架 | 无（零依赖、零构建） |
| 持久化 | `localStorage` |
| 运行方式 | 本地静态服务器（`python -m http.server`，本机 Python 3.11.9） |
| 界面语言 | 中文 |

## 3. 功能描述

### 核心功能
- 创建任务
- 标记任务完成 / 取消完成
- 删除任务
- 行内编辑：双击任务文字 → 就地变为输入框，回车确认、Esc 取消

### 扩展功能
- 筛选 tabs：全部 / 未完成 / 已完成
- 底部剩余计数（"还有 N 项未完成"）
- 「清除已完成」按钮

### 交互约定
- 新任务置于列表**顶部**（最新的在最上面）

### 日期时间
- 实时走动的时钟，秒级刷新
- 格式：`2026年10月31日 星期六 14:30:25`（24 小时制、含秒、含星期）

## 4. 项目结构

```
TODO_list/
├── index.html          页面结构
├── styles.css          样式（浅色 + 深色主题）
├── docs/
│   └── design.md       本文档
└── js/
    ├── app.js          入口：接线、绑定事件、协调各模块
    ├── store.js        数据层：localStorage 读写 + 增删改查
    ├── renderer.js     视图层：渲染列表、筛选、剩余计数
    └── clock.js        日期时间：实时刷新
```

### 模块职责
- **store.js**（数据层）：负责与 `localStorage` 交互，提供任务的增删改查与完成状态切换；是唯一接触持久化的模块。
- **renderer.js**（视图层）：负责把数据渲染成 DOM，处理筛选与计数，不直接读写存储。
- **clock.js**（功能模块）：负责日期时间的实时显示。
- **app.js**（入口）：持有各模块，绑定用户事件并协调数据层与视图层。

### 扩展约定
新增功能模块（如提醒、导出导入）时，新建独立文件（如 `js/reminder.js`），由 `app.js` 接入，尽量不改动其他模块。

## 5. 数据模型

任务对象：

```js
{
  id: "唯一标识",
  text: "任务内容",
  completed: false,
  createdAt: 1730000000000 // 时间戳
}
```

存储于 `localStorage`，以 `http://localhost:8000` 源为作用域。

## 8. 数据持久化说明

- 数据保存在**浏览器**的 `localStorage` 中，与静态服务器无关：关闭服务器、重启浏览器、重启电脑后数据仍保留。
- 数据按**源**（协议 + 域名 + 端口）隔离，务必固定使用同一端口访问（如始终 `http://localhost:8000`）；更换端口或改用 `file://` 会读不到已有数据。
- 数据按**浏览器 / 用户档案**隔离，不跨浏览器、不跨设备。
- 手动清除浏览器数据或使用无痕模式会清空数据。
- `localStorage` 无备份、无同步。如需防误删备份，可后续新增「导出 / 导入 JSON」模块。
